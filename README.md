# 🎯 Interview Coach

**AI-powered interview preparation — practice for any job, anywhere in the world.**

Interview Coach is an interactive web application that helps candidates practice interviews using AI. It generates tailored questions from any job description, listens to your answers, tracks your body language, and provides real-time feedback.

## ✨ Features

- 🤖 **AI-Generated Questions** — Paste any job description and get 7 tailored questions
- 🎤 **Voice Interaction** — The AI speaks questions aloud and listens to your answers
- 👁️ **Body Language Tracking** — Camera detects your focus and eye contact
- 📊 **AI Feedback** — Receive detailed feedback on your answers and presence
- 📄 **PDF Export** — Download your interview summary
- 🎨 **Professional Design** — Clean, corporate-grade UI with dark mode support

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| HTML, CSS, JavaScript | Frontend |
| Groq API | AI question generation & feedback |
| MediaPipe Face Mesh | Face and gaze tracking |
| jsPDF + html2canvas | PDF export |
| Web Speech API | Speech-to-text & text-to-speech |

## 🚀 Getting Started

1. Clone the repository
2. Open `index.html` in your browser (or use VS Code Live Server)
3. Your Groq API key is already configured
4. Paste a job description and start practicing
